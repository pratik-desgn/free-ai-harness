# Code of conduct

We are committed to a welcoming, harassment-free project for everyone. Be respectful, assume good intent, give actionable technical feedback, and avoid discriminatory, threatening, sexualized, or personally identifying content.

Project maintainers may remove, edit, or reject contributions and participation that violate these expectations. Serious conduct reports should be submitted privately through the repository's GitHub Security Advisory reporting flow so personal information is not posted publicly. Maintainers will review reports fairly and protect reporter privacy as far as practical.

This policy applies in project spaces and when representing the project elsewhere.
