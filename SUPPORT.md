# Support

Use GitHub Discussions for usage and deployment questions and GitHub Issues for reproducible defects or focused feature proposals. Include the harness commit, Node version, deployment method, redacted configuration names, and relevant sanitized logs.

Never attach `.env`, `state.db`, backups, session cookies, Puter tokens, provider keys, or complete request bodies containing private data. Report vulnerabilities privately as described in [SECURITY.md](./SECURITY.md).
